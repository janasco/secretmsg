Direction

Quiet, private, a little bit electric.

The current build reads as a generic indigo-on-dark template: one accent hue doing every job, gradients for emphasis, and cards that all sit at the same elevation. This direction keeps the obsidian base but spends the accent budget deliberately, tightens the type scale, and adds real depth so hierarchy comes from spacing rather than glow.

Design tokens

Contrast is measured, not guessed.

Every text colour below clears WCAG AA against all three surfaces it is used on. The shipped app's muted token sits at 4.30:1 on its background — large text only — which is why the value is nudged here. Ratios are computed in the palette check, and the repo's a11y gate will hold any eventual implementation to the same floor.

What changes if you accept this

  • Tokens first. lib/theme.dart and index.css gain the new palette; the a11y baseline is regenerated and reviewed before any screen changes.
  • Then shared primitives — button, card, input, pill, switch — so screens are rewritten against one system rather than one at a time.
  • Screen by screen, each behind the same gate. Nothing lands in one commit.
  • Any contrast regression fails the build, because tool/a11y and scripts/a11y-color.mjs already enforce that. It is not a review convention.
